Supporting code and outputs for "A Unified Reef Visual Census (RVC) and REEF Citizen Science Index" (SEDAR 94-WP-XX)

The main analyses supporting this paper can be found in folder: code/analysis.R

Outputs (figures/tables) are generated into folder: outs

The combined Bayesian index model can be found in: stan/correlated_mod_states.stan (note you will either need to direct the cmdstan path to this folder or place this file into your local cmdstan path).
